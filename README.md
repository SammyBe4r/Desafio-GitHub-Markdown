# 🚀 Desafio - GitHub Markdown

Bem-vindo ao repositório do desafio de Markdown no GitHub. Este projeto foi criado para praticar a criação de documentação clara, organizada e visualmente agradável usando Markdown.

## 📌 Objetivo

O objetivo deste desafio é:

- criar um repositório no GitHub;
- adicionar um arquivo `README.md`;
- utilizar formatação em Markdown;
- organizar informações de forma profissional;
- praticar boas práticas de documentação e colaboração.

## 🧩 Estrutura do Repositório

```bash
desafio-github-markdown/
├── README.md
├── CHANGELOG.md
└── docs/
```

## ✅ Entregas realizadas

- Criação do repositório no GitHub;
- Configuração inicial do projeto;
- Inclusão do `README.md`;
- Organização e formatação em Markdown;
- Preparação da documentação para apresentação e revisão.

## 📝 Conceitos aplicados

Neste projeto, utilizamos elementos importantes do Markdown, como:

- títulos com `#`;
- listas com `-` e `*`;
- links com `[texto](https://example.com)`;
- blocos de código com ```;
- destaque de textos com negrito e itálico;
- organização por seções.
